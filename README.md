# WEBULPA — QR MENU & DIGITAL ORDERING

Website landing page + demo menu digital untuk jasa pembuatan website QR Code.

## Isi
- index.html — landing page Webulpa
- demo.html — demo menu dan keranjang pemesanan
- css/style.css — seluruh styling
- js/script.js — animasi landing page + menu mobile
- js/demo.js — fungsi demo menu, pencarian, kategori, keranjang, checkout
- assets/ — folder untuk logo/gambar tambahan

## Cara menjalankan
1. Extract ZIP.
2. Buka `index.html` di browser.
3. Klik `Lihat Demo` untuk mencoba simulasi menu.
4. Untuk hosting gratis, upload folder ini ke GitHub Pages atau Vercel.
